# PromptStage

글 한 줄로 그림을 만드는 웹페이지예요. 계산은 허깅 페이스(Hugging Face) Space가 대신 하고, 이 페이지는 요청을 보내고 결과를 보여주기만 해서 **저사양 PC나 크롬북에서도 가볍게** 돌아가요.

파일은 `index.html` 하나뿐이라 서버도, 설치도, 빌드도 필요 없어요.

## 특징

- **여러 서버를 차례로 시도해요.** 첫 번째 서버가 한도에 걸리거나 오류가 나면 자동으로 다음 서버로 넘어가요.
- **연속 생성**을 지원해요. 1·2·4·8장을 고르면 시드를 바꿔가며 이어서 만들어요. 중간에 중지할 수 있어요.
- **서버 상태 표시**가 있어요. 각 서버가 사용 가능한지, 한도가 차서 몇 분 뒤에 풀리는지 보여줘요. (브라우저에 저장돼요)
- **입력 형식을 자동으로 알아내요.** Space 주소만 추가하면 프롬프트·시드·크기를 넣을 칸을 스스로 찾아 채워요.
- 시드 고정, 크기 선택, 갤러리, 이미지 다운로드를 지원해요.

## 사용법

1. 페이지를 열어요.
2. 프롬프트를 쓰고(영어가 가장 잘 나와요) 크기와 연속 장수를 골라요.
3. **그림 만들기**를 눌러요. 서버가 잠들어 있으면 첫 요청에 1분쯤 걸릴 수 있어요.
4. 갤러리의 그림을 클릭하면 저장돼요. 새로고침하면 갤러리는 사라지니 마음에 드는 건 저장하세요.

## GitHub Pages로 배포하기

1. 새 저장소(repository)를 만들어요.
2. `index.html`과 `README.md`를 저장소 맨 위(루트)에 올려요.
3. 저장소의 **Settings → Pages**로 가요.
4. Source를 **Deploy from a branch**로 두고, 브랜치는 `main`, 폴더는 `/ (root)`를 골라 저장해요.
5. 1~2분 뒤 `https://<사용자명>.github.io/<저장소이름>/` 주소로 열려요.

파일을 고쳐서 다시 올렸는데 예전 화면이 보이면 **Ctrl+Shift+R**(강력 새로고침)을 눌러보세요.

## 설정

페이지의 **고급 설정**에서 바꿀 수 있어요.

| 항목 | 설명 |
| --- | --- |
| Space 목록 | 한 줄에 하나씩, 텍스트로 그림을 만드는 공개 Gradio Space 주소를 적어요. 위에서부터 차례로 시도해요. |
| 허깅 페이스 토큰 | 선택 사항이에요. 넣으면 내 계정의 무료 GPU 시간으로 쓰여서 로그인하지 않았을 때보다 더 많이 만들 수 있어요. |
| 상태 초기화 | 한도나 오류로 건너뛰던 서버 기록을 지워요. |

### 토큰을 쓸 때 주의할 점

- **읽기(read) 권한 토큰만** 쓰세요. 쓰기 권한이나 결제와 연결된 토큰은 넣지 마세요.
- 토큰은 입력한 브라우저의 localStorage에만 저장돼요. 코드나 저장소에는 들어가지 않아요.
- 공용 컴퓨터에서는 다 쓰고 나서 입력칸을 비우세요.
- 토큰을 채팅, 이슈, 커밋 등 남들이 볼 수 있는 곳에 붙여넣지 마세요. 노출됐다면 허깅 페이스 설정에서 바로 삭제하고 새로 만드세요.

## 한계

- **무제한이 아니에요.** 허깅 페이스의 ZeroGPU 무료 한도는 Space마다 따로가 아니라 계정이나 IP 기준으로 함께 차감돼요. ZeroGPU Space를 여러 개 넣어도 한도가 그만큼 늘어나지는 않아요.
- 한도를 실제로 늘리는 방법은 (1) 토큰 넣기, (2) ZeroGPU가 아닌 다른 방식으로 운영되는 Space를 목록에 섞기예요. 후자는 한도가 없는 대신 느리고 불안정할 수 있어요.
- 이 페이지는 남이 운영하는 Space에 의존해요. Space가 멈추거나 사라지거나 API가 바뀌면 그 서버는 작동하지 않아요. 안 되는 서버는 자동으로 잠시 건너뛰고, 고급 설정에서 목록을 고칠 수 있어요.
- 결과 품질과 속도는 Space마다 달라요.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| "쓸 수 있는 서버가 없어요" | 안내된 시간 뒤에 다시 시도하거나, 서버를 추가하거나, 토큰을 넣어보세요. |
| 특정 서버가 계속 오류 | 서버 상태에 오류 이유가 표시돼요. 고급 설정에서 그 주소를 목록에서 지우세요. |
| 첫 요청이 아주 느림 | 잠든 Space를 깨우는 중이에요. 1분쯤 기다려보세요. |
| 예전 화면이 그대로 보임 | Ctrl+Shift+R로 새로고침하세요. |
| 다운로드가 새 탭으로 열림 | 브라우저 보안 때문에 직접 저장이 안 되는 경우예요. 열린 이미지를 우클릭해서 저장하세요. |

## 사용한 것

- [Hugging Face Spaces](https://huggingface.co/spaces) — 이미지 생성 서버
- [@gradio/client](https://www.gradio.app/guides/getting-started-with-the-js-client) — Space와 통신하는 자바스크립트 클라이언트

그림 생성 모델과 각 Space의 이용 조건은 해당 모델·Space 제작자의 정책을 따라요. 상업적으로 쓰기 전에는 사용하는 모델의 라이선스를 확인하세요.
